## polyglot?

a [polyglot](https://en.wikipedia.org/wiki/Polyglot_(computing)) is valid code in multiple formats (like multiple programming language sources, or file formats)

## quine?

a [quine](https://en.wikipedia.org/wiki/Quine_(computing)) prints itself when invoked. There are multiple types of this, check the wiki page!

### multiquine 

a quine set of programs where for every program, you can select to print any of the programs.
